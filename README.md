# 💇‍♀️ LUMÉA Beauty Salon

## Appointment Booking & Management Web App

LUMÉA is a responsive beauty salon web application that provides customers with a simple appointment-booking experience while giving salon staff tools to manage daily operations.

## ✨ Features

### Customer Side
- Browse beauty services
- View prices and service duration
- Choose a beauty specialist
- Select appointment date and time
- Add optional extras
- Book appointments
- View and manage bookings
- Responsive mobile-friendly design

### Staff & Admin
- Appointment management
- Service management
- Staff management
- Booking status tracking
- Revenue and business KPIs
- Administrative dashboard

## 🔄 Appointment Workflow

Confirmed → Checked In → In Service → Completed

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Local Storage
- Responsive Web Design
- UI/UX Design

## 🎯 Project Purpose

This project demonstrates the development of a booking and management system for service-based businesses.

It combines a customer-facing appointment experience with administrative tools for managing appointments, staff, services, and business activity.
